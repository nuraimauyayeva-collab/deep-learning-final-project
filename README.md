## About the Project

The goal of this project is to build and train a deep learning model that classifies news articles as:

- Fake News
- Real News

The model uses Natural Language Processing (NLP) and LSTM neural networks to analyze text and predict whether a news article is fake or real.

The main dataset used in this project is the Fake and Real News Dataset from Kaggle.

---

## Repository Structure

This repository follows the structure below:

- data/ — Instructions for downloading the dataset.
- notebooks/ — Jupyter/Colab notebooks for EDA and model training.
- src/ — Python source code for preprocessing and model architecture.
- reports/ — Weekly progress reports and project proposal.
- results/ — Saved plots, confusion matrices, and model results.
