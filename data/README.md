# Project Description

This project focuses on detecting fake news articles using Natural Language Processing (NLP) and Deep Learning.

The project compares traditional machine learning approaches with deep learning models.

Models implemented:
- Logistic Regression
- LSTM Neural Network

---

# Dataset

Dataset used:
Fake and Real News Dataset

Files:
- Fake.csv
- True.csv

Dataset source:
https://www.kaggle.com/datasets/clmentbisaillon/fake-and-real-news-dataset
